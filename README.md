# Auditable Financial Report Assistant

## Goal
Build a system that accepts financial reports from multiple companies, answers questions using those documents and exposes supporting evidence and calculations

## First Version
- to process text and table from annual reports
- identify companies, reporting periods, matrics and units
- retrieve evidence for questions
- calulate financila changes from cited values
- slow source pages and acknowledge insufficient evidence.

## Evaluation commitments
- Compare a simple baseline against measure improvements.
- Use manually checked questions adn a held-out test set.
- Evaluate retrieval, answer quality, citations, and numerical accuracy
- Run ablation studies to measure individual components.
- Track latency and cost
